# Website Downtime Alert System

An automated website monitoring system designed to
detect website downtime, monitor response times,
and notify administrators when websites become
unavailable or recover.

## Project Objectives

- Monitor website availability
- Detect website downtime
- Track response time
- Generate alerts
- Monitor recovery
- Automate server deployment

## Technologies

- Kali Linux
- Vagrant
- Ansible
- Nagios Core
- Nginx
- Git
- React
- Node.js
- MongoDB

## Project Status

Currently under development.
